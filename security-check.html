PRIVACY FIRST
Password analysis happens in your browser. For the breach lookup, only the first five characters of the SHA-1 hash are sent to the Pwned Passwords range API; the complete password and full hash are not sent. Do not enter a password you currently use. This checker is a security aid, not a guarantee that a password is safe.
